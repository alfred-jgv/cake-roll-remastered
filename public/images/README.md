# Image assets

- Keep local images in this folder, grouped as `hero/`, `categories/`, `about/`, and `placeholders/`.
- Use `placeholders/cake-placeholder.svg` when a catalog image is missing.
- Product photos live in the public Supabase Storage bucket `product-images`.
- Match seed paths in `prisma/seed-data/catalog.ts`, for example `products/ube-roll/01-whole.webp`.
- Prefer optimized WebP for photographic assets.
